# 首次实际减药后 730 天复发风险与逆向情景搜索

负责人①交付的是可由平台②调用的计算模块。当前可运行的模型以 260 例教学合成患者训练和验证。当前材料没有经审核的真实患者结局表；由这些数据得到的任何概率和性能都只用于工程联调。十例试交接、预测回算、约束拒绝和无命中样例均附在目录中。

## 运行入口

在 Windows 数据盘进入本目录，使用 Python 3.12 和 requirements.txt 中的版本。已有模型由本目录脚本生成，只加载来源可信且 SHA 与审计记录匹配的模型文件。

`python algorithm.py audit --input synthetic_input/ten_interfaces`  
`python algorithm.py demo`  
`python algorithm.py predict --query 正向示例.json`  
`python algorithm.py search --query 查询示例.json`

真实经批准的数据另置于新输入目录，运行 `python algorithm.py audit --input 新输入目录`，再以 `train --input 新输入目录 --out 全新输出目录` 调用。与②衔接时可导入 algorithm.forward 和 algorithm.search；模块返回概率、训练支持距离、命中候选和拒绝原因。服药方案及剂量不在搜索字段中。

## 数据契约

| 表 | 主键与含义 | 必须核对 |
|---|---|---|
| cohort.csv | 每个可关联的 patient_id、episode_id 一条首个实际开始减药的合格索引。index_date 是已执行日期，age_at_index 为当时年龄，单位年。 | ①②③共同锁定队列；重复患者或未审核拒绝。正式 origin=DEIDENTIFIED_APPROVED。 |
| outcomes.csv | 同一主键，首次经判定复发日期、死亡日期、最后可靠随访日期和审核状态。 | 日期需晚于索引且在观察期内；同日死亡复发或矛盾时间线退回③。真实方案须先确认死亡为竞争事件。 |
| baseline_fields.csv | 每个 patient_id、episode_id 和 field 一条最终审核值。state 为 known 或 unknown，source_kind 为 structured 或 verified_text。 | available_date 不得晚于索引；source_doc_id 和 review_status 必须可追溯。未知保留空，不当阴性。 |
| protocol.json | 队列、终点、索引、730 天时窗、数据来源与临床审批标识。 | 真实队列须填写 population、index、endpoint、approval_id，并使用 clinician_approved 的审核状态。 |

八个字段依次是缓解前病程（年）、减药前无发作时长（月）、起病年龄（年）、热性惊厥史、缓解前发作次数、自限性综合征、发育迟缓、减药前 EEG 癫痫样放电。二元字段用 0/1/未知。计数的文字区间留给团队审核，不能直接当作精确次数。

## 模型与验收

按患者划分开发与测试。主模型将风险时钟分成五段，按真实暴露天数拟合复发、死亡两条分段指数风险，以区间事件概率累积到 730 天；比较模型为两条原因别 Cox 模型，Breslow 处理并列事件。死亡纳入复发累积发生概率。分别在只有结构化字段与增加已核对文本字段的条件下评估。插补和标准化仅拟合开发资料。

730 天 AUC 的病例是期限内复发患者，已知无复发和先死亡者作为对照，早期失访采用训练集删失分布进行 IPCW。Brier、校准和患者 bootstrap 区间一起报告。当前区间以固定训练模型为条件；独立删失的假设、死亡定义、事件数和每个时间段的风险集须在真实队列重新检查。患者内时间重叠、中心/时间漂移和区间删失需根据真实收集方案扩展，模型不能用于决定患者减药。

逆向模块冻结已知事实，允许在有证据的未知字段或虚拟人群条件上枚举。候选必须满足年龄与病程关系、训练变量范围以及联合近邻支持。命中由同一模型复算，找不到时返回 NO_FEASIBLE_HIT 和最近的可行候选。模型预测差异用于研究假设，不能解释为治疗效果。

参考方法：[Lamberink 等](https://pubmed.ncbi.nlm.nih.gov/28483337/)、[时间依赖 AUC 与竞争风险](https://doi.org/10.1002/sim.5958)、[删失 Brier 分数](https://pubmed.ncbi.nlm.nih.gov/17240660/)。
