# 卒中后癫痫知识图谱 v0.6 平台接入版

当前数据来自用户提供的 v0.6 证据链包，并保留平台原有的紫色聚焦交互。图谱现有 192 个节点、653 条关系；问答证据 57 条、来源 41 个。新增架构 A–E 五个研究节点、对应队列与结局关系，以及两份本地交付包来源。

- `index.html` 内嵌图数据，支持离线浏览；`graph.js` 和 `theme.css` 保留平台交互与样式。
- `graph_seed.json`、`entity_catalog.json`、`evidence_claims.json`、`sources.json` 是与页面同步的数据。
- `assets/sources/D13_v0.3_模型卡.md` 及相关说明来自 D13 校正版包；研究演示会向浏览器提供冻结模型参数，不提供训练集逐例数据。
- `assets/sources/五套算法架构_跑数结果汇编.pdf` 与 `五套算法架构_代码汇编.pdf` 是项目交付文件；对应图谱条目的状态为“交付包核对”，并未独立复跑。A/B/C 使用 D13 公开真实队列，D/E 使用温州 167 例去标识真实队列；E 是观察性关联分析，不是逐例预测模型。
- D13 v0.3 冻结参数另在 `/static/d13-research/index.html` 以浏览器本地计算方式提供研究演示；不包含训练集逐例数据，也不代表临床验证。
- `validation_report.json` 与 `query_validation.json` 是原 v0.6 包的检查记录；平台增加的来源和证据另见 `INTEGRATION_MANIFEST.json`。

D13 v0.3 是公开数据的内部再分析，预测的是一年内继发性癫痫二分类标签。它不是减药后复发模型、正式 SeLECT 评分或外部临床验证。新图谱的部分来源仍标注为待核对或部分核对，问答仅检索明确列入可核对状态的条目。
