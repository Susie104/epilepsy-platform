# 癫痫复发预测：数据源、指标、数据类型与边界处理

- 整理日期：2026-11-03（北京时间）。
- 首个场景：药物控制患者首次实际启动减药后730天内复发预测。
- 用途：数据申请、院内病例整理、变量字典与研究设计讨论；这是研究准备文档，未开展真实队列建模。
- 与现有项目衔接：沿用主索引、8个基础字段及“结构化数据—LLM抽取—生存预测—约束情景搜索”路线。既有代码仍是合成数据上的二分类原型，本文件不表示代码已实现删失、竞争风险或外部验证。
- 核查边界：依据原始论文、官方数据说明及共享声明整理；部分网页正文访问受限，已结合可检索的原文内容核对。尚未下载逐项审计原始患者数据，未取得任何受限队列授权，也未完成团队人工复核。“论文有该字段”不等于“对外共享文件一定有该字段”。
- 标记说明：**有研究依据**表示既有研究使用或支持该变量；**候选指标**表示建议采集、仍需本队列验证；**待核实**表示公开说明不足。下文自拟纳排、清洗和分析规则均为项目建议，不是通用临床标准。

## 1. 先固定要预测的问题

### 1.1 首版研究定义

> 在已经获得药物控制、经判定为有计划减药的患者中，于首次实际降低任一抗发作药物（ASM）日剂量时，用当时已经可获得的信息，预测随后730天内首次经临床确认的癫痫复发。

| 项目 | 建议定义 |
|---|---|
| 主索引 t0 | 首次有证据支持的实际降低任一ASM日剂量的日期/时刻；只有建议、预约或开具未来计划，不算实际启动 |
| 预测窗口 | 固定为t0之后至t0＋730天，终点当天计入；与“两个日历年”可能有闰年差异，不混用 |
| 主要事件 | 既往癫痫的首次临床确认复发，发生在逐渐减药期间也计入；不能因发生在减药期便自动当作非目标事件排除 |
| 单独判定事件 | 急性症状性发作、心因性非癫痫发作、晕厥、仅有不明确症状；保留分类和证据 |
| 人群 | 儿童或成人尚待团队确定；非手术患者作为首版更便于保持目标一致。跨年龄/综合征适用性需单独验证 |
| 主要分析 | 保留随访时间和删失，沿用项目计划的离散时间生存模型；死亡需另外定义竞争事件 |
| 对照分析 | Cox等适当的生存模型；完整730天结局者的二分类分析只作补充，并讨论选择偏倚 |
| 输出含义 | 在相应人群和实际诊疗背景下的复发风险；不直接等于继续用药与减药的因果效果差，也不是停药指令 |

AAN与NICE支持对合适患者进行个体化评估；“无发作达到两年”不等于所有患者都适合停药。[S17][S18]

### 1.2 可以扩展，但必须分别定义的场景

| 场景 | 索引与目标 | 关键边界 |
|---|---|---|
| 首次非诱发性发作后再发 | 首次发作时预测，或在首次评估时对仍未再发者预测后续风险，二者择一 | 如果MRI/EEG在发作后才获得，不能用于“首次发作当时”预测；改用评估日时应从评估日重新计时 |
| 卒中后发生癫痫 | 卒中起病或预先设定的第7天/出院时点，预测后续晚期非诱发性发作 | 卒中后7天内与7天后的发作分开；采用第7天才已知的变量时，不能声称是卒中起病当时预测。[S19] |
| 癫痫手术后发作结局 | 手术日，或预先设定的术后评估时点 | 术后第2年ILAE/Engel等级不一定等于“730天内是否曾首次复发”；不能未经核实互换 |
| 手术后启动减药 | 手术后符合条件者实际减药日 | 这是条件于手术和此前结局的另一队列，不直接与非手术停药人群合并 |
| 长期控制后再次发作 | 已达到预设无发作时长后的评估日，预测此后的突破性发作 | 控制时长与此前稳定用药条件先规定；计划减药、自行漏服和稳定治疗下再发分别标记 |
| 完全停药后复发 | 完全停药日作为新的landmark，预测此后的风险 | 只回答“已走到完全停药者”的后续风险，不能替代启动减药场景；中途复发者不能从主队列消失 |

癫痫诊断、首次发作、急性症状性发作和复发标签需要临床判定；一次非诱发性发作也可能在满足条件时符合癫痫诊断，不能仅按诊断编码次数判断。[S20]

### 2.1 与首个场景直接相关的来源

|---|---|---|---|

| D04 | Lamberink等，2017：10项研究、1769人 | 临床变量、复发与长期结局的个体资料汇总 | 适合作为变量设计与既有模型比较依据；本轮未核实常规公开原始数据下载入口。预测工具开放不等于训练数据开放。[S03] |

| D06 | Stevelink等，2022：JME汇总2518人，其中368人尝试停药 | 综合征、治疗反应及停药后再发资料 | 仅适用于青少年肌阵挛癫痫。个体资料不允许公开释放；论文说明学术第三方复现可作例外，需所有相关中心的数据协议，不能视为普通开放申请库。[S05] |
| D07 | Contento等，2021：133名停药患者 | 临床变量、减药、复发和复发后重新控制情况 | 适合查阅字段与结局设计；本轮未核实可直接下载的患者表，也未确认常规共享条款。文章可读不等于数据可用。[S06] |

**D02需要补充的选择偏倚审查：**原文排除部分未完成计划减药、恢复原用药的患者，并包含减药后EEG指标。申请到数据后，应询问被排除者能否获得、排除是否与早期复发有关。启动减药时的预测只能使用当时已知的变量；减药后EEG应另做动态预测。原研究模型表现不能直接当作本项目的预期结果。[S01]

### 2.3 检索入口和不匹配的常见来源

- UCI、DataFountain、OpenDataLab、天池、Heywhale是检索入口。本轮没有核实到其中同时满足实际减药索引、复发时间和730天随访要求的现成队列；这不表示平台以后不会出现此类数据。
- CHB-MIT公开EEG包括停药后数天的监测，服务于难治性癫痫观察和术前评估。它可支持发作检测方法研究，不能直接回答长期控制患者减药后两年复发。[S14]
- SEER是肿瘤登记数据，缺少本任务的关键病程。SEER-Medicare需另行审批和付费，官方申请页目前说明不向美国境外释放数据；也不能把医保处方间断直接当作有计划减药。获取规则需申请时复查。[S15][S16]
- 合成数据可验证程序、教学和交互流程，不能与真实病例混合计算临床性能或证明模型有效。
- 上述停药研究和多个公开影像版本可能存在患者重叠。独立外部验证之前要核查中心、入组年份、患者编号及原始来源。

## 3. 数据类型与最小数据结构

| 层级 | 常见格式/数据类型 | 建议保存内容 |
|---|---|---|
| 患者主表 | CSV/TSV、数据库；字符串/分类/数值 | patient_id、中心、出生/年龄信息、疾病分型；身份映射表另行受控保存 |
| 减药尝试表 | 一人可对应多条记录 | attempt_id、实际减药起点、索引类别、减药意图及证据 |
| 基线变量表 | 数值、分类、布尔＋缺失状态 | 下节指标；每项附检查/事件时间、报告可用时间和来源 |
| 剂量时间序列表 | 长表 | 药名、剂型、每次剂量、频次、实际日剂量、起止时间；处方与实际服药分开 |
| 结局与随访表 | 事件长表 | 复发、临床判定、最后可靠无复发评估、死亡及行政截断；记录区间日期 |
| 原始文书与抽取表 | 本地文本/JSON | document_id、文书可用时间、证据位置、原始抽取、人工修改及版本 |
| EEG | 报告文本；有权限时保存EDF/BIDS等 | 检查条件、时长、导联、癫痫样放电、信号质量；报告与波形的权限/可得性分别确认 |
| MRI | 报告文本、NIfTI/BIDS、脑区派生指标 | 扫描和报告时间、病变类型/部位、处理版本；术前与术后资料分开 |

仅做中文病历LLM抽取，至少需要合法可用的原始中文文书及人工标注集。只有结构化表或MRI的开放数据可以检验风险模型部分，不能验证中文文本抽取准确性。


## 4. 相关指标：现有8项、扩展变量与场景专属变量

### 4.1 首版8个基础变量

以下与项目现有字段保持一致，也对应Lamberink研究的复发预测变量。**变量概念有研究依据，不代表现有演示代码复现了其系数、基线风险、缺失处理或校准。**[S03]

| 指标/字段名 | 类型与单位 | 定义与处理要点 |
|---|---|---|
| 缓解前病程 epilepsy_duration_before_remission_years | 连续数值，年 | 从起病到本次进入缓解的病程；不是起病到减药日的全部时长。保留原始时间和换算规则 |
| 减药前无发作时长 seizure_free_months | 连续数值，月 | 从最后一次符合研究定义的发作到t0。取值为0须审查是否符合“已控制”入组条件 |
| 起病年龄 age_at_onset | 连续数值，年 | 首次符合定义的癫痫发作年龄；只有“幼时起病”等模糊描述时保留区间，不能编造精确年龄 |
| 热性惊厥史 febrile_seizure_history | 是/否/未知 | 发热诱发既往癫痫发作不自动等于热性惊厥；需依据病史与临床定义 |
| 缓解前发作次数 seizure_count_before_remission | 非负整数或区间 | 记录“约5次”“≥10次”“无数次”的精度状态；不能随意把次数类别转换成精确计数 |
| 自限性癫痫综合征 self_limiting_syndrome | 是/否/未知＋名称 | 按t0前临床诊断判断，不能因随访最终控制好就倒推为自限性；保留原始命名和分类版本 |
| 发育迟缓 developmental_delay | 是/否/未知 | 保留发生时间、评估依据；不把没有记录或普通学习困难直接当阴性/阳性 |
| 减药前EEG癫痫样放电 eeg_epileptiform | 是/否/未知 | 指癫痫样异常，不等同于所有“异常脑电图”；慢波/非特异改变另记。记录检查和报告可用日期 |

### 4.2 建议同时采集的扩展指标

这里的“候选”是供模型比较的研究变量，不能直接宣称均为已验证的独立危险因素。优先级按目标匹配、时间可靠性、缺失和样本量决定，不按单因素P值决定。

| 指标组 | 建议字段 | 类型 | 在本课题中的用途与限制 |
|---|---|---|---|
| 人口学 | t0年龄、记录性别、中心、入组年份 | 数值/分类 | 描述与泛化审查；中心/年份未必应进入最终部署模型。没有出生日期时，不要强行精确还原 |
| 发作表型 | 局灶/全面/未知、是否意识受损、是否曾双侧强直阵挛、夜间发作 | 分类/多标签 | 与疾病异质性有关；记录所用分类版本，不能将“抽搐”自动归为全面起始 |
| 病因与影像 | 结构性病变、病变类型/部位、MRI正常/异常/未查 | 分类/多标签 | 临床候选与人群描述；检查缺失不等于无病变；影像派生特征是另一复杂度层级 |
| 既往病史 | 家族史、既往癫痫持续状态、神经系统体征、既往减药失败及次数 | 布尔/整数/文本证据 | 既往资料必须在t0前可知；历史减药失败与本次未来复发严格分开 |
| 疾病控制轨迹 | 达到缓解所用时间、曾尝试药物数、既往控制失败次数 | 时长/整数 | 描述治疗反应；需统一“尝试”“足量足疗程”和“失败”定义，避免中心差异 |
| 基线用药 | 当前ASM数、各药通用名/剂型/日剂量、联合治疗 | 整数/分类/数值长表 | 当前数、历来用药数、拟撤药数是不同概念；不同药物毫克数不能直接求和作为药物负荷 |
| 减药前剂量与依从性 | 实际日剂量、mg/kg/day（适用时）、基线血药浓度、既往漏服 | 连续/分类 | 候选指标；血药浓度需记录采样相对服药时点，缺数据时不推断依从性 |
| t0已知减药计划 | 拟减哪种药、拟定先后顺序、计划减量比例/间隔 | 分类/数值 | 只保留t0已知计划。实际持续时间、实际完成比例以及复发后的调整属于未来信息 |
| EEG细化 | 最近癫痫样放电、既往是否有放电、放电部位、背景异常、睡眠/清醒、记录时长 | 分类/数值 | 最近正常不抹去既往异常；检查条件需一并记录。放电频率/网络指标属探索性特征 |
| 共病与生活信息 | 精神心理共病、睡眠、饮酒、依从性相关困难 | 分类/量表/时间窗数值 | 需有可靠基线记录与适用量表；未记录保持缺失，不以一般常识补全 |
| 随访可达性 | 既往随访规律、既往跨院就诊、可联系状态 | 分类/计数 | 用于失访机制和实施可行性分析；不能把未来随访次数作为基线预测输入 |
| 化验/组学 | 肝肾功能、血药浓度；特定研究中的炎症/遗传指标 | 连续/分类/高维 | 普通停药复发首版不强行加入；需事先有问题、时间点和样本量支持，不等同于成熟生物标志物 |

停药队列中病因、治疗、EEG等信息的采集可参考原始研究；其适用人群和结局并不完全一致。[S02][S06]

### 4.3 各扩展场景的专属指标

| 场景 | 优先考虑的额外指标 | 时间与解释限制 |
|---|---|---|
| 首次发作后再发 | 是否非诱发性、夜间发作、既往神经损伤、影像病变、癫痫样EEG、是否/何时启动ASM | 发作后才完成的检查对应评估日模型；不能用未来第二次发作反过来修正基线诊断 |
| 缺血性卒中后癫痫 | NIHSS、皮质累及、血管区域、卒中机制、早期发作；可探索WBC、血小板、D-dimer等 | Dryad确实列有部分化验与病变字段，但各变量时间点、早晚发作定义及现成评分所需字段完整性待审计。[S12][S19] |
| 出血性卒中后癫痫 | 出血部位、皮质累及、体积、早期发作等 | 不能将缺血性卒中训练集直接当作出血性卒中验证；分型和测量规则需单独固定 |
| 癫痫术后结局 | 术前发作表型、病因、术式/部位、病灶和切除范围、病理、EEG/MRI特征 | 术后病理、实际切除范围只适用于它们已可用时的术后模型；不属于手术前预测的可用输入 |
| 长期控制后再发 | 达到控制所用时间、此前稳定用药时间、既往突破性发作、基线依从性与药物负荷 | “本次再发后加药”只能用于从再发时重新预测的模型，不能用于再发前预测。[S07] |

### 4.4 必须保存、但通常不是预测输入的审计字段

| 字段 | 类型/允许值 | 作用 |
|---|---|---|
| patient_id / attempt_id / center_id | 去标识字符串 | 患者去重、尝试关联、中心划分；patient_id不作为模型特征 |
| index_time / index_type | 日期或时刻；actual_taper_start等 | 区分实际减药、计划、完全停药、其他landmark |
| index_evidence / dose_before / dose_after | 证据及带单位数值 | 证明实际减量，避免仅凭处方变更定索引 |
| recurrence_time_lower / recurrence_time_upper | 日期/时刻或null | 精确时间上下界相同；模糊日期保留区间 |
| recurrence_confirmed / event_class | 确认状态；癫痫复发/急性症状性/非癫痫/待定 | 可复查结局标签；不能只保存一个0/1而丢失判定依据 |
| last_reliable_followup_date / death_date | 日期或null | 可靠无复发观察与竞争事件；末次登录系统/任意就诊日不自动算可靠随访 |
| event_status / followup_days | 复发/死亡/删失/待判；非负天数 | 为生存分析保留时间信息；当前二分类代码不会自动处理这些状态 |
| outcome_730d | 1/0/null＋原因 | 只作派生分析标签，不覆盖原始事件表；死亡/失访/待判时一般先保留null |
| event_time / report_available_time | 日期或时刻 | 临床事实发生时间与医生当时可获取时间分开 |
| source_id / source_location / evidence_text | 字符串 | 文书与证据定位；外发内容须符合原始权限和数据协议 |
| field_status | 阳性/阴性/未知/未查/冲突/不适用 | 与数值分开保存，避免将缺失变成阴性 |
| split / extractor_version / model_version | 字符串 | 复现患者划分、抽取和预测版本；不作为风险输入 |
| adjudicator_id / adjudication_date | 受控标识/日期 | 记录真正完成判定的人与时间，不预填或虚构 |

最终向现有模型传入的字段类型须与已审计接口一致。上述新状态和长表是正式研究的数据规范建议，不代表当前CSV导入器已支持。


## 5. 结局、时间与随访的边界处理

以下为建议预先写入方案和临床判定手册的操作规则。涉及发作性质、失访机制和竞争风险的选择，由临床与统计负责人最终确定，不能依靠关键词或LLM自行裁决。

| 边界情况 | 建议处理 |
|---|---|
| 医生建议减药，但实际未执行 | 不进入“实际启动减药”主队列；可留在筛选/计划队列 |
| 只有处方片数减少、换规格或续方间断 | 核对药品浓度、每次剂量、频次和实际执行；不能直接认定日剂量减少 |
| 换药交叉滴定、因毒性调整、临时漏服、自行停药 | 分别标记调整原因与执行方式；不与缓解后有计划减药混合；若扩展纳入，预先定义并分层分析 |
| 只减少一种药，其他药继续 | 若符合主索引即进入队列；不要求最后成功停用全部药物 |
| 减药中断或重新加药，但尚未复发 | 启动后自然诊疗背景下的预后分析继续随访并记录变化；不能因未成功停药就删除。若研究“持续按计划减药”，需另定估计目标与时间变化混杂/信息性删失处理 |
| 在减药期间复发 | 按主要事件判定，起点仍是最初实际减药日；不能把复发后的恢复剂量计作基线剂量 |
| 首次尝试失败后再尝试 | 首版按每位患者观察期内首个符合条件的尝试；既往院外尝试另记。使用全部尝试时按患者聚类、处理尝试相关性，且同一患者不得跨训练/测试集 |
| t0当天报告复发 | 有明确时刻并发生在实际减药后可纳入，生存时间不机械设0；仅有日期且先后不明则待判并作敏感性分析，不自动计入/排除 |
| 距t0第730天发生事件 | 在“≤730天”的固定窗口内计入；第731天不计入730天二分类事件，但保留长期事件记录 |
| 6个月复发，后续失访 | 若事件、日期和性质可靠，730天结局可判阳性；不要求复发后还必须完成两年随访 |
| 18个月无复发后失访 | 在最后可靠无复发评估处删失，不能编码为730天阴性 |
| 最后在本院就诊是第800天，但未问及发作 | 不据此断言前730天无发作；需有对该期间发作情况的可靠评估 |
| 第800天确认“自减药以来从未复发” | 若证据覆盖整个窗口，可支持730天阴性；仍需记录回顾性报告及可靠性 |
| 第800天首次得知“约半年前发作” | 按事件时间区间判定，不以第800天的知晓日期作为发作日期 |
| 只知道事件发生在第700–760天之间 | 跨730天时标签未定；优先采用区间删失方法或上下界敏感性分析，不能默认阴性，也不随意取中点 |
| 模糊发作/结局冲突 | 保留原始证据、可能事件时间和争议状态。待判事件不能作为“已知无复发”继续计算观察时间 |
| 复发前死亡 | 作为竞争事件另存；真实世界“死亡前复发概率”应估计累计发生函数。不能把死亡当普通无信息删失后直接用1－KM解释现实累计概率 |
| 先复发、后死亡 | 首次复发事件仍保留；两者同日先后不明则判定/敏感性分析 |
| 新发急性脑损伤、严重代谢紊乱或酒精相关发作 | 按急性症状性定义判定，与原癫痫复发分别记录；不能将“睡不好”等普通诱因未经判定都当成排除理由。[S19] |
| 只有先兆/局灶保留意识症状 | 可能本身属于癫痫发作。预先规定“任意确认发作”和“有特定严重度的发作”结局；外部研究排除某类发作时要重新协调标签。[S04] |
| 只有电图发作或单纯间期放电 | 与临床发作、临床电图发作分开；EEG有放电不自动等于已经临床复发 |
| 只有“癫痫”诊断编码或重新开药 | 作为待查线索，不独立作为新复发证据；可能是续方、预防或其他适应证 |
| 成人与儿童、手术与非手术、不同综合征 | 不因同名变量就强行混合；分别看入组、事件定义、基线风险及校准 |
| 日期因去标识被平移 | 核查同一患者各表是否一致平移、相对间隔是否保留；跨院关联不能仅凭平移后的绝对日期 |

### 5.1 对730天标签的最小派生规则

1. 若已确认在t0之后且不晚于t0＋730天首次复发，派生值为1；若事件日期区间完全落在窗口内，也可支持窗口内阳性。
2. 若截至窗口末已可靠确认无复发，且不存在更早的未决可能事件，派生值为0。
3. 若无已确认窗口内事件，但可靠随访不足、日期区间跨界、存在未决事件或死亡，先记为null及具体原因，进入适当的时间结局分析/判定流程。
4. 已有可靠证据确认730天后才首次复发，可支持此前窗口无复发；若事件前观察本就不完整，不能仅凭“本院首次记载”作此判断。
5. 先按时间顺序审查所有可能事件，再选“首次符合定义的事件”；不能只取列表中第一条诊断。
6. 主要终点的临床判定由指定人员完成，记录双人独立判定及分歧解决流程；LLM只辅助定位证据。

### 5.2 竞争事件与研究目标要对应

- **现实预后目标**：在实际后续诊疗下，730天内、死亡前发生复发的累计概率。死亡参与竞争风险计算；离散时间实现需同时建模相关事件转移，或采用其他适当累计发生函数方法。
- **原因别危险度**：原因别Cox可估计瞬时复发风险，但单独拟合复发模型、把死亡删失，不能自动得到现实累计复发概率。
- **继续用药与停药的治疗效果差**：需要适合的对照、治疗策略定义和因果识别条件。只在已减药者中建立预后模型，不足以估计某人“减药能造成多少风险变化”。[S02]
- 生存分析仍依赖删失机制等假设。失访若与发作/就诊行为相关，应分析原因，考虑适当权重与敏感性分析，不能以“用了Cox”视为已解决。

## 6. 指标清洗、信息可用时间与缺失

| 问题 | 建议规则 |
|---|---|
| 基线信息泄漏 | 每个变量同时保存事实时间、文书时间与可用时间。只有t0前可获取的信息进入当时预测 |
| 检查早、报告晚 | EEG检查在t0前但报告在t0后才出具，其报告结论不用于t0临床预测；若研究原始信号算法，需明确其当时可计算条件 |
| 同日文书无时刻 | 关键减药/发作/检查关系不明时，采用预定保守规则并送复核；不自行安排先后 |
| 后来补写的既往史 | 即便内容描述t0以前，也不能自动声称t0时已可获得；回顾性病史重建与可部署模型分开报告 |
| 窗口选择 | 终生病史读取t0前可靠记录；EEG、化验等近期状态预先设窗并记录距t0时间。若用6个月/12个月等窗口，应注明是研究选择并审查敏感性，不称为统一标准 |
| 未提及与否定 | “未记录热性惊厥”保持未知；只有可靠否定证据才记否。未做MRI与MRI正常分开 |
| EEG冲突 | “最近一次正常”“既往出现过放电”“仅背景慢波”分别存；不能让后一项覆盖前一项 |
| 量纲与剂量 | 保留原始值、原始单位及转换值；用药频次/剂型、体重和浓度均核对后换算。不同药物剂量不直接相加 |
| 次数或时间只给区间 | 保留上下界及原文；若模型只支持单值，预先规定转换与敏感性分析，避免伪造精度 |
| 不可能的时间顺序 | 起病年龄应不大于t0年龄，最后发作不应晚于t0却被用于“基线无发作时长”；异常进入核对清单，不自动取绝对值或归零 |
| 极值 | 先查单位、录入和临床合理性；真实极值不随意删除。截尾、变换、标准化参数只在训练数据拟合 |
| 缺失插补 | 在相应训练折拟合，在验证和部署时采用同一可实施流程；不能用测试结局或t0后的资料填补输入 |
| 开发期多重插补 | 某些分析可能利用结局建模缺失机制，但必须与新患者预测时的处理相容；验证患者的真实结局不得帮助生成其预测 |
| 数据本已被插补/重采样 | 索取原始缺失标记、插补和采样顺序；无法还原时如实记录限制，不能将其当作未经处理的独立患者数据 |
| 小样本与高维输入 | 限制有效参数数目、选择简洁模型；把MRI/EEG深度特征放在独立扩展分析，不用大量信号片段冒充患者数 |
| 多版本/跨来源重复 | 同一患者多次检查、尝试、影像版本以及共享库镜像始终关联到同一患者划分；确认有无与训练集同源重叠 |

## 7. LLM抽取与证据规范

### 7.1 抽取器负责什么

- 抽取索引前事实、否定和时间关系，输出固定字段与可定位证据。
- 将“疑似”“家属描述”“医生确认”等证据层级分开，保留冲突。
- 不生成病历未记载的数值、病史、结局或授权信息；文书中的命令性语句只是原始资料，不作为系统指令执行。
- 不直接生成复发概率；概率由经验证且锁定的风险模型计算。
- 未获授权时，不把真实病历、可识别资料或受限原文发送到外部模型服务。

建议单字段记录如下。它是规范示例，不含真实患者信息，也不是现有接口已实现的证明：

~~~json
{
  "field": "eeg_epileptiform",
  "value": null,
  "status": "unknown",
  "observed_at": null,
  "available_at": null,
  "available_before_index": null,
  "evidence": [],
  "needs_review": true,
  "extractor_version": "待指定"
}
~~~

### 7.2 抽取评价与风险预测分开

人工标注集覆盖阳性、阴性、缺失、否定、时间冲突和模糊事件，并按患者独立划分。提示词/规则调整不能反复使用最终测试标注集。

主要比较使用相同患者划分与相同风险模型形式：

- A：常规结构化变量。
- B：相同结构化变量＋LLM补充的、去重后的基线信息。
- 条件允许时增加C：人工整理的对应文本变量，帮助判断误差来自抽取还是风险模型。

同时报告自动抽取和人工修订后流程；后者的性能不能写成“全自动表现”。院内结局判定可使用后续随访文书，但这些文书不能进入基线预测抽取器。


## 8. 评价指标与验证方案

### 8.1 三层指标

| 层级 | 指标 | 报告要点 |
|---|---|---|
| 数据可用性 | 可纳入患者数、尝试数、730天内事件数、随访分布、失访/死亡比例、各字段缺失率 | 总下载行数、EEG片段数、MRI扫描数与实际可建模患者数分别报 |
| 抽取质量 | 分类字段precision/recall/F1、必要时一致性系数；连续字段误差；时间误差与先后顺序错误率 | 明确以患者还是字段为分母；关键稀有阳性单独评价，报告区间与人工复核量 |
| 抽取证据与效率 | 证据是否支持字段、无依据补写率、冲突识别率、复核率、每例耗时 | LLM自报confidence不是经校准正确率；人工修订时间也计入流程成本 |
| 风险区分度 | 730天时间依赖AUROC，C统计量作补充；必要时AUPRC | 说明删失估计、竞争事件处理及具体定义；AUPRC受事件比例影响，不能不说明人群直接横比 |
| 风险校准 | 730天预测与观察风险校准图、适当的校准截距/斜率、平均风险偏差 | 说明怎样处理删失/死亡；理想截距0、斜率1需对应具体校准方法，不能仅展示分组曲线 |
| 总体预测误差 | 730天Brier分数；必要时积分Brier分数 | 使用与估计目标相匹配的删失/竞争风险处理，并与适当的无特征基线模型比较 |
| 阈值表现 | 灵敏度、特异度、PPV、NPV及必要时F1 | 阈值在开发阶段规定；只对标签可确定或经适当调整的人群评价，不能把删失者作阴性 |
| 研究行动的效用 | 适当的决策曲线/净获益 | 行动先定义为强化随访、复核或研究分层；阈值不等于停药阈值，曲线不证明干预有效 |
| 可靠性与适用范围 | 患者级重采样区间、中心/时间/年龄/综合征分组结果、分布外输入率 | 小亚组同时报人数和事件数；样本不足时承认精度不足，不勉强排名 |
| 模型增量价值 | A与B在同一留出患者中的区分度、校准、Brier及复核成本差异 | 同时看概率质量与实施成本，不只比较最高AUROC |

报告结构可参考TRIPOD+AI，偏倚与适用性检查参考PROBAST+AI。下述划分与指标是项目分析建议，不表示仅遵循清单就已获得有效模型。[S21][S22]

### 8.2 划分、训练与样本量

1. 按患者划分，优先规划独立中心或后续时间段验证。患者的多次减药、就诊、MRI和EEG片段全部留在同一侧。
2. 样本很小时优先使用适当的重采样内部验证，不能机械切成多个很小的固定比例子集；真正独立的外部验证仍需另行取得。
3. 插补、编码、标准化、特征筛选、调参、校准和阈值选择都限定在相应开发/训练流程；验证结局保持隔离。
4. 最终验证保留原始事件比例与人群结构。重采样/合成少数类只在适用的训练步骤考虑；二分类SMOTE不应直接复制到有删失的患者-时间长表。
5. 生存模型输出730天绝对风险必须有相应累计风险计算。Cox线性评分、相对危险度或“高低组”本身不是个人复发百分比。
6. 先报告锁定模型的外部原始表现；随后重新校准应单独标为模型更新，不能把目标队列校准后的结果冒充完全独立验证。
7. 样本量根据预期事件风险、随访/删失、有效参数数目与目标精度论证；不机械使用“每变量10个事件”或照搬他人样本量。多类别变量、非线性项和交互均增加参数。[S23]
8. 预先规定主模型和主要比较。复杂算法仅在数据规模与研究问题支持时增加，不通过反复测试许多模型挑出最高测试性能。

## 9. 逆向情景搜索的边界

本节衔接现有平台方案，属于研究功能设计，不是临床干预推荐。

| 问题 | 处理原则 |
|---|---|
| 搜索目标 | 使用同一锁定模型、同一索引及时间窗。模型未校准时只能搜索评分区间，不能包装为真实风险百分比 |
| 真实患者固定事实 | 不允许改写已发生病史、已知综合征、既往发作或检查结果来满足目标 |
| 未知信息 | 未检查/未知不自动变成“正常”。可提示补充信息或作多种明确标注的假设情景 |
| 虚拟病例约束 | 同时满足年龄、病程、缓解时长、药物等单变量与联合关系；注明是虚拟组合 |
| “再等待一年减药” | 是新的决策时点，需要更新人群、治疗和期间事件条件；不能只改无发作月数而宣称等待造成的风险下降 |
| 计划减药速度/药物改变 | 预后关联模型不能确认干预效果；不依据搜索结果输出具体换药、剂量或停药指令 |
| 数据支持 | 检查候选是否处于训练数据的联合支持范围；单项都在范围内不代表组合可靠 |
| 无可行解 | 如实报告未找到，不能编造候选或放宽临床事实以强行命中 |
| 搜索评价 | 目标命中率、约束违反率、重复率/多样性、数据支持、耗时、随机种子稳定性；这些不等于患者获益 |

## 10. 实施次序与数据申请清单

### 10.1 建议的三条路径

- **保持首个场景**：优先盘点院内实际减药病例，并申请D02/D03等匹配队列。成人课题不要仅因D02易联系就混用儿童数据。
- **先用公开数据检验风险建模**：优先核查IDEAS临床表；如果转向卒中场景，再核查Dryad CSV。必须同步改研究问题和结局，不能将它们称为停药模型的外部验证。
- **完成演示**：沿用明确标注的合成数据验证抽取、界面、模型调用和情景搜索；临床性能另待真实数据研究。

### 10.2 向数据方确认的内容

1. 能否识别有计划减药的实际执行时间，以及与处方/随机分组/完全停药时间的区别？
2. 事件是任意发作、特定发作类型、临床复发，还是某年Engel/ILAE结局？是否包括先兆、仅电图发作和减药中事件？
3. 是否有事件日期或区间、最后可靠无复发随访、死亡和失访原因？阴性是否有足够窗口覆盖？
4. 是否保留减药中断、恢复用药、早期失访及被排除者？这些排除是否依赖未来结局？
5. 各字段的检查时间、报告时间和实际可用时间能否获得？EEG是结论、结构化报告还是原始波形？
6. 是原始缺失数据，还是已插补/标准化/筛选/重采样？能否获得数据字典和处理记录？
7. 是否涉及跨库/版本/既有研究重复患者？能否用于独立验证，或仅可复现原论文？
8. 可申请的文件具体包含哪些字段、多少患者/事件？能否合法支持中文文书抽取研究？
9. 是否允许预定用途、模型训练、派生模型共享及外部服务处理？申请、费用、伦理与数据协议由谁落实？
10. 是否可以先提供不含患者记录的数据字典、字段时间定义、纳排流程及汇总可得性？

### 10.3 开始建模前的交付物

- [ ] 明确成人/儿童、手术与否、允许综合征、t0、730天窗口和事件定义。
- [ ] 完成筛选流程：可纳入人数、复发事件、死亡、失访、时间不明与排除原因。
- [ ] 形成数据字典、字段时间窗、事件判定手册和缺失状态规范。
- [ ] 抽取一批病例人工重建时间线，重点审查处方与实际减量的一致性。
- [ ] 核查申请队列与目标问题的差异，决定可直接开发、可协调后验证或仅能作方法参考。
- [ ] 锁定患者级划分和独立标注子集，完成样本量论证。
- [ ] 在真实数据审计后决定模型复杂度、动态模型范围和情景搜索允许域。
