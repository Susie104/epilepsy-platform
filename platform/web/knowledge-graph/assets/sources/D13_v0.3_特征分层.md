## 脑区编码（方法学选择，非临床结论）

`range_lobe` 逐行 = 额/顶/颞/枕/岛五叶之和（diff=0）；`subcortex_lobe` 为「皮质下受累」汇总二分类，与 basal_ganglia(0.606)、paraventricular(0.632) 等高度相关但非求和。

- **主编码**：5 个脑叶分量 + `subcortex_lobe` 汇总；**弃 `range_lobe` 与 7 个皮质下分量**（basal_ganglia, capsula_interna, brainstem, epencephalon, paraventricular, centrum_semiovale, thalamus）。
- **敏感性编码**：`range_lobe` 汇总 + 7 个皮质下分量；弃 5 脑叶与 `subcortex_lobe`。
- 二者均消除共线；编码敏感性显示 S1 AUROC 0.8915（主）vs 0.8870（替代），差异极小，说明编码选择不损失信息。
