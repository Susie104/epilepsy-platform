# 模型卡：D13-S1-LR-Platt-v0.3

## 基本信息

- 模型 ID：`D13-S1-LR-Platt-v0.3`
- 状态：研究演示冻结版（research_demo_frozen），非临床验证
- 前身：`D13-S2-LR-Platt-v0.2`（v0.2 误把 S2 设为主模型）
- 模型类型：L2 逻辑回归 + Platt 概率校准
- 随机种子：20261107

## 用途与人群

- 预测目标：D13 报告的一年内继发性癫痫二分类标签 `second_epilepsy`。
- 适用人群：D13 筛选队列（成人新发缺血性/腔隙性卒中，关键数据完整、随访可得、排除既往卒中/TIA/癫痫等）；主分析 21,457 例（age≥18）。
- 不适用：连续卒中人群、出血性卒中、无随访数据者；不能外推为「首次晚期无诱因发作」或时间到事件风险。

## 特征

- 主特征集 S1（28 特征，主编码）：人口学 + NIHSS + 既往史 + 初始脑影像（5 脑叶分量 + subcortex_lobe 汇总）+ 血管。
- 弃用（主编码）：`range_lobe`（=五脑叶之和）与 7 个皮质下分量（共线/重叠）。
- 校准参数：验证集 Platt（斜率 0.7555，截距 −0.5873）。

## 指标（测试集，锁定后评估）

AUROC 0.8915（raw=calibrated）、AUPRC 0.2866、Brier 0.03853(raw)/0.03828(cal)、Log loss 0.13956(raw)/0.14142(cal)。

## 必须随模型一起展示的限制（warnings，已写入 model_bundle.json）

1. 公开数据研究演示，不能作为临床诊断或治疗依据，不是最终临床研究结论。
2. D13 是筛选研究队列，不是连续卒中人群。
3. 公开 CSV 已上游随机森林插补，「0 空值」≠原始完整，不能据此声称可部署。
4. 无患者 ID、事件日期、死亡日期、随访截止日期；仅二分类，不做 Cox/Fine-Gray。
5. dvt 定义与实验室单位问题留待任务三核实，本模型不裁决。
6. 结局仅为一年内继发性癫痫二分类标签，不回答发作日期、死亡竞争风险或因果效应。
7. 空白输入使用训练集中位数，不代表正常值；变量关联不是因果效应。
