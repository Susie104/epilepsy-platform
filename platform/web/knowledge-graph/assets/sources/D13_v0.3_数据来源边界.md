# D13与卒中网络逐例数据的来源说明

D13及本阶段补充卒中数据均来自网络公开资料，不是医院正式交付队列。

## 已纳入D13模型的数据

- Dryad D13第8版；
- DOI：`10.5061/dryad.w0vt4b92c`；
- 文件SHA-256：`be84a00921702c45e5c9d250176602b2c62ed96ac41716dca8893b0c5be49d4b`。

## 未纳入D13模型的外部网络数据

### 温州数据

- DOI：`10.3389/fnagi.2021.707732`；
- 167例逐例记录，其中缺血性卒中111例；
- 所有记录来自卒中后7天内发生早期发作的患者；
- 只能作为字段验证和有限的疾病特定分析，不能代表一般卒中人群。

### 苏州/安徽数据

- DOI：`10.17632/gnvp2s43cx.1`；
- 149例急性缺血性卒中；
- 有NIHSS、TOAST、日期和90天mRS；
- 没有癫痫结局，不能用于PSE模型训练或验证。

### Winder数据

- DOI：`10.1111/jon.13110`；
- 28例论文逐例表；
- 有梗死部位、TOAST和发作类型；
- 缺发作时间、死亡和末次随访，不能构成时间到事件队列。

## 合并限制

- 三批数据患者来源、纳排标准和结局不同；
- 没有跨库患者链接；
- 不能把344条记录相加后称为一个患者队列；
- 不能把温州早期发作队列的PSE比例当作卒中总体发病率；
- 外部网络数据不进入D13 v0.3训练。
