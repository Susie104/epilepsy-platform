# 卒中后癫痫知识图谱 v0.6 查询示例

1. 搜索 `D13 v0.3`，查看 S1 主特征集、S2 探索集、S3 泄漏敏感性集及模型卡来源。v0.2 节点保留，并标记为已被 v0.3 取代。
2. 搜索 `算法架构A`、`算法架构D` 或 `算法架构E`，查看五套真实队列研究分别对应的 D13 或温州队列、结局及结果汇编。E 是观察性关联分析，不是逐例预测模型。
3. 搜索 `SeLECT-ASyS` 或 `SeLECT-EEG`，查看各自的评分组件、适用人群和原研究定位；不要将评分套用到 D13。
4. 搜索 `D13`，查看 11 项数据质量限制和 `CANNOT_CALCULATE` 关系。
5. 搜索 `温州`、`苏州` 或 `Winder`，核对网络来源及 `NOT_MERGED_WITH` 关系。
6. 搜索 `Modified SeLECT 2.0`，查看 72 小时 NIHSS 替换说明；完整分数表仍标记为部分核对。

机器可读的预期节点和关系见 `query_examples.json`。
