# 节点动效融合

参考：https://wordlink.orionsheep.com/study 。观察公开页面中的弹性展开、保留节点位置的聚焦切换、吸附悬停轮廓、拖拽连线和松手定位后，以原生 SVG 与独立弹簧计算实现对应交互；未引入参考网站代码或运行时服务。

紫色背景、玻璃面板、荧光绿焦点与节点分类色保持原样。新加入场节点从局部展开，共有节点沿保留的位置和速度平滑过渡；切换期间旧节点淡出。连线端点跟随节点，点击和缩放保持平滑；背景可拖动平移。点击“重新布局”恢复位置并重播展开。

拖动节点不会误触实体跳转，松手后保留位置；键盘搜索、实体按钮、分页、五条路径、D13 对照与来源访问继续可用。系统设置减少动态效果时立即停止过渡；页面隐藏时暂停动画，静止时停止逐帧计算。

实现：motion.js，少量 graph.js 渲染挂钩和 theme.css 交互样式。科学内容、151 个节点、428 条关系和来源附件不变。

本次动效专项验收：16 项通过；另复跑图谱原有 28 项验收和主题 20 项验收。证据：knowledge-graph-motion-summary.json。
