# 知识图谱 v0.3 变更记录

日期：2026-11-07。

## 任务1：补全SeLECT评分变量层

- 新增 `ScoreComponent` 实体类型。
- SeLECT 1.0新增5个评分变量节点。
- SeLECT 2.0新增6个评分变量节点。
- 新增 `HAS_SCORE_COMPONENT` 和 `SCORES_CONCEPT` 关系。
- 每个评分变量记录精确定义、计分规则、时间条件、来源及D13映射限制。

- 新增D13-S2-LR-Platt-v0.2模型节点。
- 新增S1、S2、S3三个FeatureSet节点及全部字段关系。
- 新增D13内部重复内容组感知再分析Study节点。
- 新增9个DataQualityIssue节点，覆盖筛选人群、上游插补、变量时点、DVT定义、脑叶汇总共线、年龄冲突、S2定位、患者ID缺失及外部验证缺失。
